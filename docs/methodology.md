# Methodology

The reproducible flow is validation → non-destructive cleaning → lexicon-based text sentiment → derived features → scaled K-Means → human cluster interpretation → human shop labels → Random Forest → linear regression. Candidate cluster counts are compared with inertia and silhouette score. Classification is evaluated against a majority-class baseline using stratified data. Regression reports test metrics, standardized coefficients, residual diagnostics, and multicollinearity flags. K-Means clusters are patterns, not proof of fake reviews. Regression describes cross-sectional association, not future growth or causality.
